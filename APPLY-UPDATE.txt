JeePHP 2.7.0 Development Console update

1. Back up your current project.
2. Extract JeePHP-v2.7.0-development-console.zip into the project and replace matching files. Keep your .git folder and local .duck file.
3. Run composer dump-autoload if the new DeveloperConsole class is not found.
4. Use APP_ENV=local and APP_DEBUG=true in .duck for development. The Console tab appears on HTML pages at the bottom-right.
5. Set APP_ENV=production and APP_DEBUG=false on production servers.

Push from VS Code
- Open Source Control, review each file, stage the framework changes, commit, and Sync/Push.
- Do not stage .duck or secret values.
- Publish a new Composer release only after choosing a version, pushing its Git tag, and confirming Packagist has imported it.
