JeePHP 1.0.0 source update

1. Back up your project and keep the `.git` folder and local `.duck` file.
2. Extract the update archive into the JeePHP source/project folder and replace matching framework files.
3. In VS Code Source Control, review and commit the changed files. Do not stage `.duck` or secrets.
4. Run `php jeep --version`; it should print `JeePHP 1.0.0`.
5. To enable optional authentication, run `php jeep activate AuthO`.
6. To enable roles/permissions, run `php jeep activate RolesO`.
7. Run `composer dump-autoload`, configure the database in `.duck`, and run `php jeep migrate`.
8. For the first RolesO manager, create/sign in to an AuthO account, then run `php jeep role:assign USER_ID admin` and `php jeep permission:grant admin roles.manage`.

Activation creates source files and migrations. Run migrations only after reviewing them and backing up important production data. The `v1.0.0` Git tag was already used in an earlier release; do not move or overwrite an existing tag. Choose a new immutable release tag when publishing these updates to Packagist.
