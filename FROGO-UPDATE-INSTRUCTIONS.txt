JeePHP FrogO update

1. Extract this ZIP into your JeePHP project root (the folder containing composer.json). Allow it to overwrite README.md and src/JeePHP/Packages/PackageActivator.php.
2. Run: composer dump-autoload
3. Run: php jeep package:list
4. Run: php jeep activate FrogO
5. Start the app: php jeep serve
6. Open http://127.0.0.1:8000/frogo. The default /frogo/ping request confirms FrogO is connected.

FrogO only opens for local/development APP_ENV, APP_DEBUG=true, and a direct loopback connection from this computer. Requests run in the browser, stay same-origin, and are not saved.
