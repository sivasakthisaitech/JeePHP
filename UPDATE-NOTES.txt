JeePHP 1.0.0 — optional packages and version command

What changed
- Added `php jeep --version` and the source version setting in config/app.php.
- Added `php jeep activate AuthO` for registration, login, account, logout, CSRF-protected forms, password hashing, session rotation, and sign-in attempt limits.
- Added `php jeep activate RolesO` for roles, permissions, management routes/views, and helper APIs.
- Added CLI bootstrap commands to assign a role and grant a permission.
- Package activation is allowlisted, repeat-safe, stops on file conflicts, and creates migrations without applying them automatically.

After activation
1. Run `composer dump-autoload`.
2. Set the database settings in `.duck` and create the database.
3. Run `php jeep migrate`.
4. Create an account at `/auth/register`.
5. If using RolesO, identify that account ID, then run `php jeep role:assign USER_ID admin` and `php jeep permission:grant admin roles.manage`.
6. Sign in and open `/roles`.

Security scope
AuthO is a strong starting scaffold, not a promise that every possible attack is prevented. Use HTTPS, keep dependencies/server software current, review authorization at every protected route, and add verification/recovery flows when needed.
